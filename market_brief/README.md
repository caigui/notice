# 每日市场数据采集 + 钉钉表格推送

随时可执行，**直接 `python market_brief.py` 即可**（无需任何参数）：自动取「最近一个已有完整数据的交易日」——
当天收盘且数据已发布则记当天，否则自动回落到上一交易日。按日期写入 CSV（同日重跑覆盖），
并以**表格形式推送到钉钉群**。

## 指标清单与口径

| # | 指标 | 口径 / 数据源 |
| --- | --- | --- |
| 1 | 两融余额（沪深北）及变动 | 融资+融券，沪、深、北三所合计；三所发布日期可能不同，取三所都有数据的最近交易日对齐后求和（BSE 原始单位万元已换算为亿元） |
| 2 | 布油 / WTI 价格和涨跌幅 | 新浪外盘期货实时（布伦特、NYMEX原油） |
| 3 | 美日韩指数涨跌幅 | 标普500 / 纳指 / 道指为日线收盘涨跌幅（早间运行为隔夜收盘）；日经225 / 韩国KOSPI 为新浪实时行情（盘中=当日最新价，收盘后=当日收盘，失败回落日线），另记点位；另附小型纳指期货（E-mini NQ 连续，新浪 hf_NQ 实时，涨跌幅按昨日结算价计算） |
| 4 | A股成交额及主力净流入 | 成交额 = 上证指数 + 深证综指（东财日K，失败时自动降级腾讯实时行情）；主力净流入 = 东财大盘资金流（上证+深证，唯一东财强依赖项） |
| 5 | 大盘拥挤度 + TMT 拥挤度 | 口径同用户 a_share_analyzer.py：大盘拥挤度 = 成交额前 5% 个股成交额 ÷ 全 A 成交额；TMT 拥挤度 = TMT（科技/传媒/通信，清单 `tmt_industry_stocks.csv`，1815 只）成交额 ÷ 全 A 成交额；另记 TMT 在前 5% 成交额中的份额。数据源东财全 A 快照，被墙时自动降级新浪全 A 列表分页抓取（约 55 页）。快照口径随运行时间自动切换：盘前=上一交易日收盘值，盘中=当日实时（备注标注），收盘后=当日收盘值 |
| 6 | 创业板指/中证红利比率 | 收盘价之比，及较前一交易日变化 |
| 7 | 期货黄金/白银 | COMEX 黄金、白银实时价和涨跌幅；金银比 = 金价 ÷ 银价（两位小数）；黄金 CFTC 非商业持仓（COMEX，基金/投机盘）：多头/空头/净多、空头全历史百分位、报告日、空头与净多周变化。取数：futuresbench（CFTC 官方 COT 整理，最新 52 周）补最新一期 + akshare 全历史底座算分位，两源重叠期零误差交叉验证；CFTC 周报周五发布截至上周二数据（滞后约 3 天） |
| 8 | 美债利率 | 2Y / 10Y / 30Y 收益率（中债-美债收益率曲线） |
| 9 | 两市成交量 | 沪深两市总量（亿股） |
| 10 | 沪深300 股债收益差 | 盈利收益率(1/滚动PE) − 10年期国债收益率（PE 来自中证指数官网「滚动市盈率」） |
| 11 | M2 总量及同比环比 | 央行货币供应量，最新月度（约滞后 2 周发布） |
| 12 | 前 5% 个股成交额占比 | 东财全 A 快照按成交额降序，前 5% 只个股成交额之和 ÷ 全部 A 股成交额；口径随运行时间自动切换（见上） |
| 13 | 主力净流入 | 东财大盘资金流向（data.eastmoney.com/zjlx/dpzjlx.html 同源数据）：上证+深证主力净流入合计 |
| 14 | 信贷脉冲 | (新增人民币贷款 TTM − 上年同期 TTM) ÷ GDP TTM，参照中金「信贷脉冲领先股市约 6 个月」框架；社融接口更新滞后故用贷款口径，另记录沪深300近12月涨跌幅供领先滞后对照 |
| 15 | A股主要股指 ERP | 上证50 / 沪深300 / 中证500 / 中证1000 各自的盈利收益率(1/滚动PE) − 10年期国债收益率，PE 取中证指数官网 |
| 16 | 股债利差（乐咕） | 乐咕乐股 `stock_ebs_lg` 内置沪深300股债利差（接口原值为小数，已转百分比），附全历史分位，用于判断股市贵不贵 |
| 17 | 国债收益率 + 信用利差 | 中债信息网曲线：国债 1Y/3Y/5Y/10Y/30Y 看利率绝对水平；信用利差 = 3Y AAA 中票 − 3Y 国债（该接口无国开曲线，改用国债作基准，口径写入备注） |
| 18 | 可转债转股溢价率 | 东财全市场可转债列表 `bond_zh_cov`，取「债现价>0 且溢价率非空」的在用券（约 300+ 只）中位数，附样本只数。**勿用集思录 `bond_cb_jsl` 作主源**：游客态仅返回 30 条且按溢价率**升序**排列（即全市场最低的 30 只），中位数会严重低估（实测 6.55% vs 全市场 54.59%），故仅作应急兜底并标注偏差 |
| 19 | 偏债混合基金指数滚动3年年化 | 申万宏源偏债混合基金指数（807330），756 个交易日滚动窗口年化收益 + 历史分位（均值回归逻辑）；直连申万接口关闭证书校验，失败回落 akshare |

## 使用步骤

### 1. 安装依赖

```bash
python -m pip install akshare requests schedule
```

> 钉钉推送只用 `requests`，**不需要** `dingtalkchatbot`（加签逻辑已内置在 `dingtalk_utils.py`）。

### 2. 配置钉钉机器人

1. 钉钉群 → 群设置 → 智能群助手 → 添加机器人 → **自定义**
2. 安全设置勾选「加签」，复制 Webhook 和加签密钥（以 `SEC` 开头）
3. 打开上一级 notice 目录的 `dingtalk_utils.py`（全工程共用一份），把顶部 `DEFAULT_WEBHOOK` / `DEFAULT_SECRET` 换成你自己的

### 3. 运行

```bash
# 默认：采集一次 + 推送钉钉（不需要任何参数）
python market_brief.py

# 只采集写 CSV，不推送
python market_brief.py --no-send

# 换表格渲染风格：md（默认）/ html / align
python market_brief.py --style align

# 额外推一份到微信（Server酱，需先填 market_brief.py 顶部 SENDKEY）
python market_brief.py --wechat

# 另存本地 PNG 报表（默认已关闭）
python market_brief.py --image

# 常驻模式：每天 09:02 自动执行
python market_brief.py --daemon
```

或直接双击 `main.bat`（等价于 `python market_brief.py`，可带参数：`main.bat --no-send`）。

- CSV 数据文件：`market_data.csv`（按日期 upsert，同日重跑覆盖）
- 运行日志：`market_brief.log`

### 4.（推荐）用 Windows 计划任务代替常驻脚本

常驻脚本关机/注销就停了，用系统计划任务更可靠。以管理员身份运行：

```bash
schtasks /create /tn "MarketBrief" /tr "\"你的python.exe路径\" \"C:\Users\admin\Documents\MCGA\market-brief\market_brief.py\"" /sc daily /st 09:00
```

> 注意：`python.exe 路径`用 `where python` 查，必须是装了 akshare 的那个（安装依赖时用 `python -m pip install` 确保装到同一个环境）。用计划任务时脚本不需要常驻，每次到点自动跑一轮。

删除任务：`schtasks /delete /tn "MarketBrief" /f`

## 钉钉表格样式

钉钉官方 markdown **不支持标准表格语法**，只有三种折中方案，`dingtalk_utils.py` 都已实现：

| 风格 | 参数 | 效果 |
| --- | --- | --- |
| 管道表格 | `--style md`（**默认**） | 标准 Markdown 表格，钉钉渲染最像真表格，实测群内显示正常 |
| HTML 表格 | `--style html` | PC 端带边框表格；移动端部分版本会露出 `<table>` 标签 |
| 等宽对齐 | `--style align` | 空格对齐的纯文本表，任何客户端都不会乱，但不算真表格 |

涨跌用 `▲ / ▼` 箭头标注，移动端也能一眼看出方向。

每个表格控制在 3 列以内（指标 / 数值 / 说明），手机端不会横向挤断。七组：**A股** / **估值与流动性** / **股债性价比（ERP）** / **转债与偏债混合** / **贵金属（黄金/白银/金银比 + CFTC 多空持仓）** / **海外与商品** / **利率**。

## 备注

- **执行时间与数据日期**：脚本随时可跑，`数据日期` = A 股最近一个已收盘交易日。15:05 前运行自动剔除当日未完成 K 线（即取上一交易日）；15:05 后若数据源已发布当日数据则记当天，否则自动回落到上一交易日（备注标注「今日数据未发布」）。逐项指标再按各自数据源最新可得日期取数（如两融天然为 T-1，月度 M2/信贷脉冲为最新发布月份）。
- 快照类指标（拥挤度/前5%占比）口径随运行时间自动切换：9:30 前 = 上一交易日收盘；9:30–15:00 = 当日盘中实时（备注标注）；15:00 后 = 当日收盘。
- 实时类指标（布油/黄金/纳指期货/全球指数）任何时候都取最新可得价。
- **两融口径说明**：统一采用「沪深北两融余额 = 融资余额 + 融券余额」，沪（上交所汇总，元）+ 深（深交所汇总，亿元）+ 北（北交所汇总，万元）三所同日对齐求和，与媒体/东财「沪深北两融余额」口径一致。不再单独记录仅含融资的「融资余额」。
- 创业板指（新浪）与中证红利（中证官网）收盘价发布时间可能不同，比率按两者共有的最新交易日对齐计算。
- CSV 若正在 Excel 中打开导致无法写入，脚本会自动另存为 `market_data_YYYY-MM-DD.csv`，关闭 Excel 后重跑即写回主文件。
- 某项数据源临时故障时，脚本会跳过该项并在推送消息和 CSV 备注列中标明，不影响其他指标。
- **推送格式**：钉钉 markdown 分组表格（七组：A股 / 估值与流动性 / 股债性价比 / 转债与偏债混合 / 贵金属 / 海外与商品 / 利率），表头加粗、板块标题加粗。
- 图片报表默认**关闭**（钉钉用表格即可）。需要本地存档时加 `--image`，仍会生成 `market_brief_YYYY-MM-DD.png`，红涨绿跌着色，依赖 `matplotlib`。
- 微信推送默认**关闭**，加 `--wechat` 才走 Server酱（需填 SENDKEY，免费版每天限 5 条）。
